## 💼 Professional Experience

### ServiceNow

**Software Engineer**

#### 🔹 Workflow Data Fabric Platform

A workflow data fabric platform that brings customers' analytical data from multiple external sources through **zero-copy connectors** and processes it through a **medallion architecture**.

The platform enables users to build **declarative data pipelines**, configure transformations through a visual experience, and execute those pipelines to transform and process their data.

#### What I Work On

* Built the **SQL generation engine** that converts transformation configurations defined in JSON into executable SQL.
* Designed and implemented the transformation layer of the SQL generator using:

```text
Transformation JSON
        ↓
Intermediate Representation / AST
        ↓
Final SQL / dbt Model
```

* Built support for complex transformations including **row-based transformations, joins, and unions**.
* Worked on **incremental pipeline processing**, including handling complex transformation scenarios while maintaining incremental execution.
* Developed **data preview** functionality for data pipelines, allowing users to preview transformation results before executing the complete pipeline.
* Built and enhanced transformation capabilities used by the declarative pipeline experience.
